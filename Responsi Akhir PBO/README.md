Petunjuk Run:

Pengguna dapat secara manual menghidupkan lampu melalui menu nomor 1, mematikan lampu melalui menu nomor 2, dan mengatur tingkat kecerahan lampu melalui menu nomor 3.

Pengguna dapat melakukan simulasi sensor cahaya melalui menu nomor 4 dengan memasukkan nilai intensitas cahaya dalam satuan lux.

Pengguna dapat melihat informasi perangkat melalui menu nomor 5.

Pengguna dapat menghitung perkiraan konsumsi energi melalui menu nomor 6 dengan memasukkan durasi penggunaan lampu dalam jam.

Pengguna dapat mengakhiri program melalui menu nomor 0.

Langkah Compile:
1. Buka terminal atau Command Prompt.
2. Masuk ke direktori utama proyek.
3. Jalankan perintah berikut: javac -d bin src/ResponsiAkhir/*.java

Langkah Run:

Setelah proses compile berhasil, jalankan: java -cp bin ResponsiAkhir/Main
